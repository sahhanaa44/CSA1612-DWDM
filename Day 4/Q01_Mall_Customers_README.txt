Open CSV in WEKA Explorer > Preprocess. Set CustomerID and Gender to ignored; select AnnualIncome and SpendingScore (or numeric attributes) for clustering. Cluster tab > Choose SimpleKMeans > set numClusters to 5 > Start. Visualize cluster assignments. The source only shows five sample rows; add more customer rows if your faculty expects a full mall dataset.
